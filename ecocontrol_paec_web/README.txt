# EcoControl PAEC — Prototipo web

Sitio demostrativo basado en los documentos del anteproyecto EcoControl PAEC.

## Cómo abrirlo
1. Extrae el ZIP.
2. Abre la carpeta `ecocontrol_paec_web` en Visual Studio Code.
3. Abre `index.html` en un navegador. También puedes usar la extensión Live Server.

## Incluye
- Inicio / landing page.
- Panel con indicadores.
- Tabla de actividades, búsqueda y filtros.
- Formulario para agregar y editar actividades.
- Eliminación de registros de demostración.
- Adjuntar el nombre de un archivo como evidencia visual.
- Diseño adaptable a computadora y móvil.

## Importante
Este es un prototipo frontend. Los registros no se guardan permanentemente y el inicio de sesión no autentica usuarios. El archivo que se selecciona como evidencia solo muestra su nombre; no lo sube a un servidor. Para convertirlo en sistema funcional, hay que conectar PHP y MySQL/MariaDB con XAMPP y crear las tablas, sesiones y operaciones CRUD.
